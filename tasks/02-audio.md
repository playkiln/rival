# Task 2 — Audio (music + SFX)

**Goal:** a full soundscape — looping music, a speed-tracking engine note, and
a sound for every meaningful event — behind persisted toggles, volume
controls, and the platform's mute-all button.

**Owners:** Gerard delivers 4 tracks from Suno. Claude synthesizes all SFX
locally (script-generated, licence-clean), transcodes everything, and does all
integration.

**Depends on:** Task 1 (the Settings panel and the `Preferences` split).

---

## Part A — Music: what Gerard delivers

Drop files into `asset-inbox/music/` with exactly these names (wav/mp3/m4a —
highest quality Suno offers, WAV preferred):

| file | what it is |
|---|---|
| `race-loop.wav` | in-lap music, must loop |
| `menu-loop.wav` | calmer sibling for main menu / settings / pause, must loop |
| `result-loop.wav` | end-screen bed, must loop |
| `best-sting.wav` | short one-shot fanfare on a new personal best |

### Suno step-by-step

1. On suno.com use **Custom** mode, mark the track **Instrumental** — no
   lyrics anywhere in this game.
2. Paste the style prompt below into the style/description field. Leave
   lyrics empty.
3. Generate 2–3 candidates per track; judge with headphones. For the three
   loops, judge the **middle** of the track — Claude cuts intro/outro and
   loops a stable mid-section, so a great middle beats a great intro.
4. Download the highest-quality audio Suno offers for the winner.
5. Rename to the exact filename above, drop into `asset-inbox/music/`.

**Don't worry about:** exact length, seamless loop points, silence at the
ends, or file size. `tools/process-music.sh` (ported from Snake) trims,
loop-crossfades the seam, loudness-normalizes and encodes to OGG + M4A.

### Prompts

**`race-loop.wav`** — aim ~90–120 s generated (Claude keeps ~60 s):

> Driving instrumental synthwave for a night-time time-trial racing game,
> around 128 BPM. Pulsing analog arpeggio, punchy gated drums, warm bass
> throb, a single confident lead line, tense but not aggressive — focused,
> in-the-zone concentration music. Constant steady energy throughout, no
> intro buildup, no breakdown, no outro, no vocals, seamless loopable
> background music.

**`menu-loop.wav`**:

> Calm ambient synthwave menu music, same warm analog palette as a night
> racing game soundtrack, around 90 BPM. Slow pad chords, sparse plucked
> arpeggio, soft sub bass, minimal percussion, patient and atmospheric with a
> hint of anticipation. Instrumental, constant mellow energy, no intro, no
> outro, seamless loopable menu music.

**`result-loop.wav`**:

> Reflective instrumental synthwave outro bed for a racing game results
> screen, around 100 BPM. Warm analog pads, a simple wistful melody, light
> percussion, satisfied and a little melancholy — the feeling of coming back
> into the pits. Instrumental, steady, no intro, no outro, seamless loopable.

**`best-sting.wav`** — Suno makes full songs, not 4-second stings; that is
fine, Claude cuts the sting out of the opening:

> Short triumphant synthwave fanfare, bright ascending analog synth melody
> over a punchy drum hit, celebratory and clean, the sound of a new track
> record. Starts immediately with no build-up, short and sweet,
> instrumental.

### Music behaviour (Claude implements)

- Menu loop on main menu / settings / pause; race loop from the countdown
  through the lap; result loop on the end screen. Crossfade ~300 ms.
- `best-sting` ducks the loops, plays, then the result loop fades back in —
  the same duck/queue mechanism `GameAudio.playClearedSting()` already uses in
  Snake.
- Music survives RACE AGAIN without restarting from bar one (loops **pause**
  on the way out and resume mid-phrase, exactly as Snake does).
- Host pause / tab hidden → `sound.pauseAll()`, resume restores.

## Part B — SFX: Claude synthesizes, no delivery needed

Generated by a Node/WebAudio script checked into `tools/generate-sfx.mjs`
(ported from Snake's, so every sound stays re-tweakable), baked to
`public/assets/audio/sfx/`.

| id | sound | trigger |
|---|---|---|
| `engine` | **looping** engine note, playback rate driven by car speed | whole lap; the headline sound |
| `tyres` | **looping** slip/scrub layer, gain driven by slip angle | when `leaveMarks()` sees slip |
| `offtrack` | **looping** gravel rumble, gain fading in over ~120 ms | while `car.offTrack` |
| `checkpoint-up` | bright tick | checkpoint crossed ahead of the ghost |
| `checkpoint-down` | duller tick | checkpoint crossed behind the ghost |
| `countdown-tick` | F1-style single light beep | 3, 2, 1 |
| `countdown-go` | brighter release tone | GO |
| `lap-done` | clean confirming chord | valid lap crossing the line |
| `lap-invalid` | flat two-note refusal | invalid lap (checkpoint missed) |
| `medal` | short rising chime, one per medal tier (pitch shifts by tier) | medal earned on the end screen |
| `ui-tap` | micro-click | any button press |
| `ui-toggle` | second distinct click | a settings value changes |
| `pause-in` / `pause-out` | soft two-note in/out pair | pause / resume |

Notes on the three loops — this is where the feel is won or lost:

- **Engine pitch tracks real speed**, not throttle: Rival's speed is constant
  on tarmac and drops off it, so the note sagging off-track is free, honest
  feedback. Map `Math.hypot(vx, vy)` to playback rate over a narrow band
  (roughly 0.8–1.15) — wide pitch swings on a constant-speed car sound broken.
- All three loops start silent at the countdown and ramp, so a session never
  begins with a click.
- They must stop on finish, pause, abort and terminate. A ringing engine loop
  over the end screen is the most likely bug in this task; check it first.

Deliberately excluded: a per-frame steering swish (constant input, constant
noise), and any voice.

## Part C — Integration (Claude)

- **`src/game/GameAudio.ts`** — new, ported from Snake's and extended with the
  looping-layer handling above. Every play and fade goes through Phaser's
  Sound Manager; no side `AudioContext`, per the boot contract.
- **`index.html`** — `window.PlaykilnOptions` gains `audio: true` alongside
  `storage: true`. **Only once host mute genuinely silences everything**
  (DESIGN §11): declaring it falsely hands players a dead mute button.
- **Mute layering**: host mute is `game.sound.mute` (already wired in
  `main.ts`) and sits *above* the in-game preferences — the platform button
  silences everything regardless of the settings panel, and unmuting restores
  whatever the player had chosen.
- **Autoplay**: the host grants `allow="autoplay"`, but still unlock the
  WebAudio context on first pointer/key input as a fallback for local preview
  and strict browsers.
- **Formats**: OGG + M4A per music track (Phaser picks per browser), SFX as
  small OGGs. Keep added audio well under ~10 MiB.
- **Manifest**: no change; `usesNetwork` stays false.

## Acceptance criteria

      return; RACE AGAIN causes no restart hiccup.
- [ ] Engine note tracks speed and sags off-track; no loop survives finish,

- [ ] Every SFX in the table fires on its trigger.
- [ ] Toggles and volumes work live, persist across a reload (via the save
      document, Task 1 §4), and default to ON at moderate volume.
- [ ] Platform mute-all silences the game completely with no errors, and
      unmuting restores the player's own settings.
- [ ] Tab hidden / host pause silences audio; resume restores it.
- [ ] Loops are seam-free on headphones.
- [ ] `playkiln validate` passes; package size still comfortable.
